Status codes

Three-digit codes that say how a request went.

2xx means success (200 OK). 3xx means redirect (301, 308). 4xx means the client asked for something wrong (404 Not Found, 403 Forbidden). 5xx means the server broke (500, 503). Crawlers watch these closely: a 'soft 404' (an error page that returns 200) confuses search engines.
