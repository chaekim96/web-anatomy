Database

Where data that changes is stored and queried.

Relational databases (Postgres, MySQL, SQLite) store tables and are queried with SQL. Document and key-value stores (Firestore, Redis, Durable Objects) trade structure for speed or flexibility. A site needs one as soon as visitors create data.

SELECT title, slug FROM projects WHERE published = true ORDER BY date DESC;
