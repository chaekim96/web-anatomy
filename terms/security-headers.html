Security headers

Response headers that tell the browser to lock things down.

Strict-Transport-Security forces HTTPS. Content-Security-Policy limits where scripts can load from. X-Content-Type-Options stops the browser guessing file types. Referrer-Policy controls what other sites learn about where visitors came from. You can check a site's headers at securityheaders.com.

Strict-Transport-Security: max-age=63072000; includeSubDomains
X-Content-Type-Options: nosniff
Referrer-Policy: strict-origin-when-cross-origin
