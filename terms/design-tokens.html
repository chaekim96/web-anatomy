Encyclopedia / CSS

Design tokens

Named values for color, spacing and type, defined once.

Custom properties like --accent and --space-2 keep a site consistent and make themes possible. Dark mode becomes a matter of redefining the tokens under prefers-color-scheme: dark.

:root { --ink: #111; --paper: #fff; }
@media (prefers-color-scheme: dark) {
  :root { --ink: #eee; --paper: #111; }
}
