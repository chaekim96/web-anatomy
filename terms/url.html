URL

The full address of one resource on the web.

A URL has parts: scheme (https), host (example.com), optional port, path (/work), query (?tab=2) and fragment (#top). The fragment never reaches the server. The browser keeps it for scrolling and in-page routing.

https://example.com:443/work?tab=2#top
