Web server / host

A computer that answers HTTP requests with files or generated pages.

This can be a box you manage (nginx on a VPS) or a platform that hides the server entirely (Vercel, Netlify, Cloudflare Pages, GitHub Pages). Platforms trade control for zero maintenance.
