Rendering: SSG, SSR, CSR

Where and when the HTML gets built.

SSG (static generation) builds the HTML at deploy time. SSR (server rendering) builds it for each request. CSR (client rendering) sends an empty shell and lets JavaScript build the page in the browser. CSR is the riskiest for SEO and GEO, because some crawlers, including many AI crawlers, don't run JavaScript and see an empty page.
